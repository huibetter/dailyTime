# DailyTime 整体优化阶段三：编辑器与交互可靠性计划

## 阶段目标

在不改变 Markdown 原文存储格式的前提下，提升预览安全性、格式兼容性、编辑稳定性和核心键盘交互。

## 实施范围

1. 使用成熟 Markdown 解析器替换手写预览转换逻辑。
2. 使用 HTML 清洗器限制危险标签、属性和协议，继续支持标题、列表、代码、链接和图片。
3. 保留现有 `htmlToMarkdown` 作为编辑区转换兼容层，先保证已有内容不丢失。
4. 为 Markdown 渲染、标题提取、导出和不安全 HTML 输入增加回归测试。
5. 优化保存状态、空状态和错误状态的可见反馈。

## 验收标准

- Markdown 标题、列表、引用、代码、链接、图片和删除线可正常预览。
- `<script>`、事件属性和危险协议不会进入渲染结果。
- 现有文档导出内容不改变主要结构。
- `npm run typecheck`、`npm run test`、隔离构建和目标文件格式检查通过。
- 阶段完成后更新 `docs/history/` 并创建本地 Git 提交。

## 提交拆分

1. `docs: 制定整体优化阶段三编辑器计划`
2. `refactor: 使用安全 Markdown 渲染管线`
3. `test: 补齐编辑器渲染回归用例`

## 暂不处理

- 不在本阶段重写富文本编辑器。
- 不在本阶段引入协同编辑、版本历史或附件实体化存储。
